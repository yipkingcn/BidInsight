# AI 项目内容分析器 - 功能说明

## 🎯 功能目标

为已采集的招标项目提供 **AI 智能分析**能力，自动提取关键商业信息：
- 项目建设内容（做什么）
- 项目预算金额（花多少钱）
- 分包信息（是否有多个标包，每个包的内容和金额）

## ✨ 核心价值

### 对于客户经理
- ⚡ **提升效率**: 无需逐个打开详情页阅读，批量分析数十个项目仅需几分钟
- 🎯 **精准定位**: 快速找到符合预算范围和业务方向的商机
- 📊 **数据驱动**: 基于结构化数据进行统计分析和趋势预测

### 对于决策者
- 💰 **成本可控**: 使用高性价比模型（gpt-4o-mini），100个项目分析成本约5美分
- 🔄 **流程自动化**: 采集 → 分析 → 导出，全流程自动化
- 📈 **可扩展性**: 支持批量处理，轻松应对大规模数据

## 📦 模块说明

### 1. `analyzers/project_analyzer.py`

**核心类：`ProjectAnalyzer`**

```python
class ProjectAnalyzer:
    def __init__(
        self, 
        api_key: Optional[str] = None,
        base_url: Optional[str] = None,
        model: str = "gpt-4o-mini",
        temperature: float = 0.0
    )
    
    def analyze(self, content: str) -> ProjectAnalysis:
        """分析文本内容，返回结构化结果"""
        
    def analyze_from_html(self, html_content: str) -> Optional[ProjectAnalysis]:
        """从完整 HTML 中提取并分析"""
```

**数据模型：**

- `ProjectAnalysis`: 项目分析结果
  - `overall_construction_content`: 整体建设内容
  - `overall_amount_wan_yuan`: 整体金额（万元）
  - `packages`: 分包列表
  - `has_multiple_packages`: 是否有多个分包

- `PackageInfo`: 分包信息
  - `package_name`: 分包名称
  - `construction_content`: 建设内容
  - `amount_wan_yuan`: 金额（万元）

### 2. `analyze_projects.py`

批量分析工具，主要功能：
- 读取 CSV 文件（来自 `csg_bidding.py`）
- 遍历每个项目的 URL，获取详情页
- 调用 `ProjectAnalyzer` 进行分析
- 输出增强版 CSV（原列 + 新增分析列）

### 3. `test_analyzer.py`

快速测试脚本，使用内置示例验证分析器功能。

## 📊 输出字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 整体建设内容 | 文本 | AI 提取的项目概述 | "采购网络安全工控机，包括A型50台和B型30台" |
| 整体金额（万元） | 数值 | 项目总预算 | 250.0 |
| 是否有分包 | 文本 | "是"或"否" | 是 |
| 分包数量 | 数值 | 分包个数 | 2 |
| 分包详情 | JSON | 分包列表详情 | `[{"package_name":"第一包",...}]` |

## 🚀 使用流程

### 步骤 1: 配置 API Key

```bash
export OPENAI_API_KEY="sk-your-key"
export OPENAI_BASE_URL="https://api.openai.com/v1"  # 可选
```

### 步骤 2: 采集项目数据

```bash
python crawlers/sites/csg_bidding.py \
  --keywords-file configs/keywords/csg_units.txt \
  --since 2024-11-15 \
  --with-detail
```

输出：`data_csv/20251127_140500.csv`

### 步骤 3: AI 分析

```bash
# 测试前5条
python analyze_projects.py data_csv/20251127_140500.csv -n 5

# 批量分析全部
python analyze_projects.py data_csv/20251127_140500.csv
```

输出：`data_csv/analyzed_20251127_141000.csv`

### 步骤 4: 查看结果

用 Excel 或其他工具打开输出文件，查看新增的分析列。

## 💡 提示词设计

核心提示词位于 `ProjectAnalyzer` 的 `prompt` 属性中，主要包含：

1. **系统角色定义**: "你是一个专业的招标文件分析助手"
2. **任务说明**: 提取建设内容、金额、分包信息
3. **金额归一化规则**: 元→万元、千元→万元、亿元→万元
4. **分包识别指导**: "第一包"、"标包1"等表述
5. **输出格式要求**: 结构化 JSON（通过 Pydantic 模型约束）

## 🎨 金额归一化逻辑

| 原始单位 | 转换公式 | 示例 |
|---------|---------|------|
| 元 | ÷ 10,000 | 1,000,000元 → 100万元 |
| 千元 | ÷ 10 | 2,500千元 → 250万元 |
| 万元 | 直接使用 | 250万元 → 250万元 |
| 亿元 | × 10,000 | 0.5亿元 → 5,000万元 |

这个逻辑在 GPT 提示词中明确说明，由 AI 自动执行。

## 📈 性能与成本

### 速度
- 单个项目分析时间: 2-5秒（取决于网络和 API 响应速度）
- 100个项目预计耗时: 5-10分钟

### 成本（基于 gpt-4o-mini）
- 单项成本: ~$0.0005（0.0005美元）
- 100个项目: ~$0.05（5美分）
- 1000个项目: ~$0.50（50美分）

### 资源消耗
- 内存: < 500MB
- CPU: 低（主要等待网络 I/O）
- 网络: 每个项目约 2-3 次请求（详情页 + API 调用）

## 🛡️ 错误处理

1. **详情页无法访问**: 记录错误，继续处理下一个项目
2. **无法提取"2.项目概况"**: 返回 None，在输出中标注空值
3. **API 调用失败**: 捕获异常，记录失败原因，继续处理
4. **金额提取失败**: 字段置为 `null`，不影响其他信息提取
